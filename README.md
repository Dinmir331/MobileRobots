# Мобильные роботы. Алгоритмы построения маршрутов

## Необходимое ПО
Visual Studio Code, Python

# Выполненные задания

## Лабораторная работа №1. 
Ручное управление мобильным роботом (Роботино) с помощью мыши при наблюдении сверху (видеокамера). Исходные данные - карта местности с пятью статическими препятствиями, полученная с камеры (вид сверху). Требуется визуализация текущих координат робота в процессе управления и отображение пройденного маршрута в отчёте.

## Лабораторная работа №2. 
Реализация и сравнительный анализ трёх алгоритмов планирования траектории: A*, Дейкстры и одного по выбору (Жадный алгоритм, Двунаправленный поиск пути и т.д.). Исходные данные - карта местности с пятью статическими препятствиями, полученная с камеры (вид сверху). Задача - построение оптимального маршрута между двумя диагонально расположенными точками А и Б. Сравнение алгоритмов выполняется по интегральному критерию.

## Лабораторная работа №3. 
Планирование движения в условиях динамических препятствий. Постановка аналогична ЛБ2, с дополнением: обнаружение и учёт перемещающихся препятствий осуществляется с помощью сонаров или видеокамеры.

## Курсовой проект. 
Автономная навигация робота по сглаженным сплайновым траекториям на основе технического зрения

## Условия:

размер поля: 220 на 220 см
диаметр робота Robotino v4: 50 см

# Этапы работы

### 1. Инициализация и конфигурирование системы
- Загрузка настроек (режимы, параметры камеры, цвета препятствий, морфология, габариты, скорости).
- Инициализация ArUco-детектора с оптимизированными параметрами.
- Создание окон интерфейса и подключение камеры/видеофайла.

### 2. Калибровка рабочей области (Perspective Correction)
- Расстановка четырёх углов поля кликами мыши.
- Вычисление матрицы гомографии и обратного преобразования для карт `remap`.
- Сохранение/загрузка калибровочных точек в JSON-файл.
- Диалог при запуске: использовать сохранённую калибровку или перекалибровать.

### 3. Локализация робота по ArUco-маркеру
- Детектирование маркера с заданным ID на каждом кадре.
- Вычисление координат центра маркера и ориентации.
- Преобразование пиксельных координат в мировую систему (X — вниз, Y — вправо).

### 4. Сегментация препятствий по цветовым диапазонам
- Перспективное преобразование кадра в вид сверху (`cv2.warpPerspective`).
- Перевод в HSV и бинарная фильтрация по нескольким заданным цветам (чёрный, красный, зелёный, синий).
- Исключение областей робота и маркера из анализа.
- Морфологическая очистка (Opening, Closing).
- Упрощение до выпуклых оболочек и фильтрация по минимальной площади.
- Слияние близких препятствий.

### 5. Построение карты безопасности и планировочной маски
- Расширение препятствий на безопасный радиус `OBSTACLE_SAFE_RADIUS_M` (зона avoidance).
- Создание планировочной маски с дополнительным отступом `PLANNING_EXTRA_RADIUS_M`.
- Нанесение границ рабочей области с отступом `BORDER_MARGIN_M`.

### 6. Планирование пути на графе сетки
- Перевод планировочной маски в граф (свободные/занятые ячейки).
- Реализация четырёх алгоритмов поиска:
  - A* (с Евклидовой эвристикой)
  - Dijkstra
  - Greedy (жадный поиск по эвристике)
  - Bidirectional A*
- Выбор алгоритма через параметр `PATH_ALGORITHM`.
- Масштабирование карты для ускорения (`plan_scale`).
- Оптимизация очереди с использованием `heapq` и преобразование в 1D-индексы (для A*).

### 7. Постобработка маршрута: упрощение и сглаживание
- Упрощение ломаной алгоритмом Дугласа–Пекера (опционально, `SIMPLIFY_EPSILON_PX`).
- Сглаживание Catmull–Rom сплайном с равномерным ресамплингом (`SPLINE_RESOLUTION`).
- Возможность включения/отключения сглаживания (`PATH_SMOOTHING`).

### 8. Управление движением робота
- Выбор целевой точки на маршруте с упреждением (`lookahead`).
- Расчёт скоростей в мировой системе координат для голономного робота.
- Плавное торможение при приближении к финальной цели.
- Динамический выход из препятствия (локальный поиск ближайшей свободной ячейки при попадании в опасную зону).
- Асинхронная отправка команд через сокет/HTTP с защитой от блокировок (`threading`).

### 9. Визуализация в реальном времени
- Отображение исходного кадра с углами поля (режим калибровки).
- На transformed-кадре: маркер робота, целевая точка, пройденный трек, планируемый путь, текущий waypoint.
- Полупрозрачное наложение областей препятствий и безопасных зон.
- Служебная информация: скорости, координаты, одометрия, режим работы.

### 10. Логирование и анализ переходных процессов
- Запись реальной траектории с метками времени.
- Сохранение исходного запланированного пути для сравнения (в условиях динамического перепланирования).
- Построение линейных графиков X(t) и Y(t) с наложением модельной (плановой) траектории.
- Масштабирование модельного времени под реальную длительность движения.
- Автоматическое сохранение графиков в папку `trajectory_logs` при достижении цели.

### 11. Коммуникационный модуль (Robotino_communication.py)
- HTTP-интерфейс для получения одометрии (`/data/odometry`).
- HTTP-интерфейс для отправки скоростей (`/data/omnidrive`).
- Обработка ошибок с ограничением частоты сообщений.
